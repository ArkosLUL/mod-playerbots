# Combat reach audit after core update `2026_11_06_01`

Read-only audit, 2026-11-22. The core update rewrote `creature_model_info` combat reach and bounding radius for 2520 displays (1516 change in play). This lists the raid strategy sites that still assume an old reach. Effects are worked out from core formulas and SQL, not traces: confirm in a trace before changing a constant. Each boss's next polish round takes its items; a later docs pass takes the comment-only ones.

Core rules used: a DB reach under 0.1 loads as 1.5 (`ObjectMgr.cpp:1763-1764`); in-game reach is model reach × scale (`Creature.cpp:3593-3610`); melee range = both reaches + 4/3, minimum 5 (`Unit.cpp:807-811`), plus 2.66 yd when both move; a chasing creature stops at both reaches + 0.5 (`TargetedMovementGenerator.cpp:35-44, 256-260`); creature-cast area spells measure centre distance, player-cast ones add the creature's reach (`Spell.cpp:9507-9524`).
