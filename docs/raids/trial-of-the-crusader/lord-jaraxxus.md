# Lord Jaraxxus

Raid-wide facts and the code layout: [README.md](README.md).

Interrupt Fel Fireball (66532, 2.5 s cast), purge or spellsteal Nether Power, heal through
Incinerate Flesh (instant, undispellable heal absorb). Spread for Legion Flame, kill Mistress of
Pain adds, avoid Infernal Volcano AoE. Touch of Jaraxxus is commented out in this core
(`boss_lord_jaraxxus.cpp` `JustEngagedWith`).
